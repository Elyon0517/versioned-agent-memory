# Reproduce the showcase

Verified locally on 2026-10-24 with Python 3.12 / Node 24 as applicable and Chromium headless.
Commands run from the repository root. Browser screenshots use synthetic example data.

## Commands

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev,mongo]'
pytest -q
ruff check .
mypy
python examples/showcase.py
# Optional browser tooling, kept outside the SDK's runtime dependencies:
uv run --with playwright playwright install chromium
uv run --with playwright python examples/test_showcase.py
```

## What was verified

- 89 SDK tests passed using the test adapters and optional mock dependencies.
- Ruff and mypy passed (mypy requires the optional MongoDB dependency).
- The visual generator asserts idempotent replay, correction protection, other-user memory
  and session isolation, empty active memory after forgetting, and blocked resurrection.
- Browser acceptance passed: open the generated HTML, expand a real receipt, inspect Boston
  and its correction evidence, verify JSON outcomes, and check a 390px layout.
- `docs/screenshots/memory-lifecycle.png` comes from that browser run.
- This is an in-memory reference demo, not a production MongoDB/Redis integration test.
  Forgetting means logical revocation, not physical deletion of all backups.

## Reading the images

Screenshots are committed so GitHub renders them immediately. They are generated by the
browser acceptance scripts, not hand-composed mockups. Re-running a capture can change
layout, animation timing and measured latency slightly. Browser traces on test failure
are local debugging artifacts and are not committed.
